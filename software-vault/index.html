Tool · experimental source alpha for technical Linux users

OPEN SOURCE · SOURCE ALPHA LOCAL INFRASTRUCTURE

PLAG IN, Private Local AI Gateway

An experimental Linux source alpha for technical users who need evidence of locality and reproducible model operation. It provides exact local model identity, bounded embedded libllama serving, authenticated loopback transport and metadata-only inference receipts. The accepted result covers one synthetic L3 trial, not production readiness, repeated-run reliability, model quality or comparative performance.

Python 3.14+ · embedded libllama adapter · authenticated loopback transport · Apache-2.0

Tool · research kit to download

OPEN METHOD · PUBLIC PILOT RESEARCH KIT

AI Research Starter

A starter pack for planning, investigating, challenging and documenting a checkable research project with an AI assistant: a starting prompt, working rules, a method menu, a project notebook, two small checkers and a worked example. A public pilot edition shared for trial and feedback; it is not evidence that the pack improves research quality.

Markdown guides · Python stdlib checkers · CC BY 4.0 documents, MIT scripts

Tool · command-line tool

OPEN SOURCE · FIRST RELEASE PUBLISHING

PDF link fixer

Finds links in a PDF printed by Chromium that point at files on your own disk, and can rewrite them as relative links without changing any other byte of the file. It reads one narrow kind of PDF and reports anything else as incomplete.

Python 3 standard library · poppler-utils · MIT code, CC BY 4.0 documents
