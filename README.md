# NMAIResearch.github.io

The landing page for NMAI Research: AI-assisted research, model experiments and creative production. Open-access research, tools and source code, with project-specific version records.

**Live:** https://nmairesearch.com/

One front door to the Research, Software, Game, Music and Video Vaults, linking the interactive tools and the open-access studies on Zenodo, with file-level licence notices and ORCID [0009-0003-4213-7769](https://orcid.org/0009-0003-4213-7769).

- **Interactive tools:** self-contained front-ends over frozen or versioned research datasets.
- **Studies:** reproducible working papers and analytical notes built from public data.
- **Games, music and video:** made with AI, in the Game, Music and Video Vaults.

Static pages with no build step, except `portfolio-map.html`, which `reproduce_portfolio.py` generates. `index.html` is the homepage and `hu/` holds the Hungarian pages; add a new tool or paper to `research.html`.
